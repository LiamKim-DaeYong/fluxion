# handoff

인수인계 예고(`[인수인계 예고]`)를 받으면 작업 단위가 끝나는 응답에서 아래 순서로 처리한다.

1. `.claude/handoff/<역할>.md`를 아래 형식으로 덮어쓴다.
2. 예고에 적힌 빈 플래그 파일 `.claude/handoff/<터미널>.flag`를 만든다.
3. 사용자에게 "인수인계를 남겼고 곧 /clear된다"고 한 줄로 알리고 응답을 끝낸다.

## 형식

```markdown
# 인수인계 (<역할>, <YYYY-MM-DD HH:MM>)

## 진행 중 작업
- <이슈 번호, 브랜치, 지금 단계. 끝난 일은 적지 않는다>

## 결정 사항
- <이번 세션에서 사용자와 정한 것과 이유 한 줄>

## 다음 할 일
1. <바로 이어서 할 일부터>

## 열린 질문
- <사용자 답을 기다리는 것, 보류한 쟁점. 없으면 "없음">

## 참고
- <다시 읽어야 할 파일, 명령, 메시지 ID>
```

## 원칙

- 새 세션이 이 파일만 읽고 바로 이어갈 수 있게 쓴다. 대화 요약이 아니라 상태를 적는다.
- 40줄 이내로 쓴다. 레포, Issue, `CLAUDE.md`에 이미 있는 내용은 경로만 적는다.
- Run ID, 터미널 handle은 적지 않는다. SessionStart 훅이 다시 찾는다.
- 인수인계 전 대화는 `claude --resume`으로 되돌릴 수 있다.
